# 🛡️ OceanShield AI — Frontend Operations Dashboard

Advanced maritime cybersecurity and tactical electronic warfare C2 dashboard built with Next.js 15, React 19, and Tailwind CSS.

## 🚀 Key Features

* **Interactive Leaflet Tactical Map**: Multi-tile ocean cartography (CartoDB Positron, Esri Satellite) with real-time AIS heading chevrons and pulsing threat rings.
* **Animated Trajectory Replay Engine**: Decomposes nominal AIS navigation from synthetic GPS spoofing injections with step-by-step playback and speed multipliers.
* **8 Dedicated C2 Modules**: Fleet Monitor, Threat Intelligence, Spoofing Cases, Maritime Chokepoints, RF Spectrum Gauges, Sat-AIS Constellation, AI Anomaly Models, and Live Telemetry Logs.
* **Forensic Investigation Drawer**: Optical reconnaissance satellite HUD, 6-factor AI confidence breakdown, and chronological incident logs.

## 🚦 Getting Started

### 1. Installation
\\ash
cd frontend
npm install
\
### 2. Development Server
\\ash
npm run dev
\
Open [http://localhost:3000](http://localhost:3000) to view the live dashboard.

### 3. Production Build
\\ash
npm run build
npm run start
\
